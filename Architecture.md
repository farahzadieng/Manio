# Manio architecture (v1.5)

Manio is a static React PWA. IndexedDB is its only authoritative data store. There is no server API, login, sync, or balance calculation. Start with the file for the feature you are changing.

Filter and period state stays in `App.tsx` across tab switches.                                                                                                                                                          |

## Transaction flow

The editor validates inputs, resolves the selected category/source, and writes a transaction. New expenses preselect the source on the most recently **created** transaction with an active source; if there is no such transaction, they use the newest active source. Income starts without a source. The user can change either selection. A star places the saved transaction on Home as a repeat shortcut. Repeating starts a new ID with the original amount/category/source/necessity/note, today's date, and an unset star.

## Monthly reminder flow

Settings stores `lastBackupAt` and `lastBackupReminderMonth`. If the journal is onboarded and has no backup or reminder claim in the current **local Gregorian** month, `claimBackupReminder` updates that month atomically and the app shows a 12-second toast. It checks on launch, focus, visibility return, and hourly while open. Exporting JSON updates `lastBackupAt`. Dismissal, opening an editor, or changing tabs hides the toast; it does not recur until the next eligible month. The PWA cannot display a timed toast while closed.

## Safe change path

For a persisted field, update the Zod schema, IndexedDB version and migration, demo data, backup compatibility, and focused tests. Do not wipe stores during upgrades. For UI changes, test narrow mobile layout and both themes. Keep financial data local and avoid client secrets or analytics. Run `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e`, and `npm run e2e:offline` before release. See `docs/IMPLEMENTATION_STATUS.md` and `docs/QA_REPORT.md` for current boundaries.
