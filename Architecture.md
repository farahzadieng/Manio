# Manio architecture (v1.0)

This is a static React PWA. IndexedDB is the only authoritative store. There is no server API, login, sync, or balance calculation. Read the files below for the feature you are changing; a full repository scan is usually unnecessary.

| Concern                         | Start here                                                                                   | Mechanism                                                                                                                                                                                                                                                                                                      |
| ------------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Screens and interactions        | `src/App.tsx`                                                                                | Home, transactions, reports, obligations, settings, and editors live in one component tree. Shared data is refreshed from IndexedDB after writes.                                                                                                                                                              |
| Data contracts and calculations | `src/lib/domain.ts`                                                                          | Zod schemas, safe integer toman amounts, local civil ISO dates, Jalali conversion, normalized search, report filters and totals. Transaction category/source names and necessity are snapshots.                                                                                                                |
| Persistence                     | `src/lib/db.ts`                                                                              | Native IndexedDB `manio-local`, schema version 3. Stores: paymentSources, categories, transactions, obligations, recurrenceRules, settings, metadata. `put` validates; multi-store writes use one transaction. The v3 upgrade adds `starred: false` to older transactions. Never delete a store to migrate it. |
| Backups                         | `src/lib/backup.ts`                                                                          | Versioned JSON export/import, reference validation, atomic replace/merge, and CSV export. Merge keeps the local record on ID collision. Older v2 backups parse with `starred: false`.                                                                                                                          |
| Demo/onboarding                 | `src/lib/demo.ts`                                                                            | Idempotent first-run seed; separate empty start. Demo replacement requires explicit confirmation in Settings.                                                                                                                                                                                                  |
| Obligations                     | `src/lib/recurrence.ts`, `src/App.tsx`                                                       | Due instances have distinct IDs. Completion can offer a separate transaction; it does not create one silently. Calendar fallback copies event details.                                                                                                                                                         |
| Date input and amounts          | `src/components/DatePicker.tsx`, `src/components/AmountInput.tsx`, `src/lib/amount-input.ts` | Jalali UI converts to local ISO dates. Amounts format Persian grouping while editing and parse to integer tomans before persistence.                                                                                                                                                                           |
| PWA and styles                  | `vite.config.ts`, `src/style.css`, `public/`                                                 | Workbox precaches static assets. Updates prompt before reload, with a manual check in Settings. CSS tokens handle light/dark and safe areas. No catch-all `_redirects` rule.                                                                                                                                   |

## Transaction flow

The editor validates amount and note, resolves the chosen category/source, then writes one transaction. New expenses preselect the active source with the latest `createdAt`; income starts without a source. A star sets `starred` on that transaction. Home lists starred records as repeat shortcuts. Repeating opens a new editor with the original amount/category/source/necessity/note, today's date, a new ID, and an unset star. Editing the original record preserves its ID and star state. Archiving a category or source does not remove historic snapshots.

## Safe change path

When a persisted field changes, update its Zod schema, the IndexedDB version/migration if old records need normalization, demo data, backup compatibility, form writes, and focused tests. Keep imports atomic and check cross-store references before mutation. For UI changes, test narrow mobile layout and both themes. Keep financial data local and avoid client-side secrets or analytics. Run `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e`, and `npm run e2e:offline` before a release. See `docs/IMPLEMENTATION_STATUS.md` and `docs/QA_REPORT.md` for current boundaries.
